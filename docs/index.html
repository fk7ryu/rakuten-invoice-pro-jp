主な機能

楽天公式領収書をPDF一括保存

期間指定やチェックボックスで選んだ注文の注文詳細から「発行する」を自動実行し、公式の領収書PDFを一括ダウンロードします（宛名自動入力にも対応）。

経理ソフト向け自動リネーム

「20261117_5100円_Rakuten_注文番号.pdf」のように日付・金額・注文番号で自動整形。年/月別フォルダ分けや変数カスタマイズにも対応しています。

注文一覧CSV出力＆重複スキップ

ダウンロードした全件の注文日・注文番号・金額・商品名をまとめたUTF-8（BOM付き）CSVを同時出力。取得済み注文のスキップ機能も搭載しています。

よくある質問（FAQ）

購入履歴や領収書のデータが外部サーバーに送信されることはありますか？

いいえ、一切ありません。すべての処理はお使いのChromeブラウザ内（ローカル環境）のみで完結します。決済とライセンス判定のみExtensionPay（Stripe）を利用します。

領収書が未発行の注文でも取得できますか？

はい。詳細設定の「領収書の宛名」を設定しておくと、未発行の注文でも自動で宛名を入力して発行・PDF保存を行います。

Amazon版もありますか？

はい。Amazon領収書一括ダウンローダー もあわせて公開しています。
